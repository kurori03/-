# バッチまとめて実行の仕組み

複数のバッチを **`まとめて実行.bat` のダブルクリック1回** で順番に動かします。
共有フォルダに置けば、どのPCからでも同じものを実行できます。

## フォルダ構成

```
batch\
├─ まとめて実行.bat   … これをダブルクリックする（中身は触らなくてよい）
├─ 設定.bat           … 全バッチ共通の設定（データの場所など）
├─ jobs\              … 実行したいバッチを置く場所
│   ├─ 01_○○.bat
│   ├─ 02_○○.bat
│   └─ 停止中\        … 一時的に止めたいバッチはここへ移動（実行されない）
└─ logs\              … 実行結果の記録（日時_PC名.log）
```

## 使い方

| やりたいこと | 方法 |
|---|---|
| 全部実行する | `まとめて実行.bat` をダブルクリック |
| バッチを追加する | `jobs\` に置く。ファイル名の先頭の番号順に実行される（`01_`、`02_` …） |
| 順番を変える | ファイル名の番号を変える |
| 一時的に止める | `jobs\停止中\` などサブフォルダへ移動する |
| 毎日自動で動かす | タスクスケジューラで `まとめて実行.bat /auto` を登録（最後に止まらない） |
| 失敗しても次を続けたい | `設定.bat` の `STOP_ON_ERROR` を `0` にする |

## jobs に置くバッチのルール

1. 正常終了は `exit /b 0`、失敗は `exit /b 1` で終わらせる
2. `pause` や入力待ちを入れない（自動実行が止まってしまう）
3. フォルダの場所は直接書かず、先頭で `call "%~dp0..\設定.bat"` を読み込んで `%DATA_DIR%` を使う
4. 実行中のフォルダは `jobs\`。他のファイルは `%~dp0` からの場所で指定する

## 困ったとき

- **「別のPCで実行中のため、開始できません」と出る**
  表示された人が実行中です。終わるまで待ってください。
  誰も実行していないのに出る場合は、前回途中で止まっています。`実行中.lock` フォルダを削除してから再実行します。
- **どれかが失敗した**
  `logs\` の最新ログで、何番目のどのバッチが何番の終了コードで止まったか確認できます。

## 文字コードについて

`.bat` ファイルは **Shift_JIS（ANSI）** で保存してください。
メモ帳で編集したときは「名前を付けて保存」で文字コードを **ANSI** にします（UTF-8 だと日本語が文字化けして動きません）。

## 個人情報の扱い

- 実データは `設定.bat` の `DATA_DIR`（アクセス権を絞った共有フォルダ）に置き、この `batch\` フォルダや GitHub には置かない
- ログには実行したバッチ名と結果だけを記録し、データの中身は書き出さない
