# 回送・納車依頼ボード

自動車ディーラーのパートスタッフ向け行動管理表。依頼者が空き時間に作業を依頼し、管理者が承認するまでを1画面で扱います。

## 機能

- **週間ボード** — 縦にスタッフ、横に7日間。勤務日を色分けし、各日の残り空き時間（`空き 3.5h`）を表示します。休みの日はハッチング表示で依頼できません。
- **日別タイムライン** — 7:00〜20:00の時間軸に勤務時間帯と各依頼を実寸で配置します。
- **依頼の作成** — ボードのセルをクリックすると、その担当・日付で依頼フォームが開きます。直前の依頼の終了時刻から空きスロットを自動提案します。勤務日外・勤務時間外・時間重複は入力中に警告します。
- **承認フロー** — 申請中 → 承認 / 差戻し → 完了。差戻しには理由を付けられ、操作履歴（誰がいつ何をしたか）が依頼ごとに残ります。承認・差戻しは役割が「管理者」の人だけが行えます。
- **依頼一覧** — ステータスと担当者で絞り込めるカード一覧。
- **スタッフ設定** — 名前・拠点（練馬 / 三鷹）・勤務曜日・勤務時間を編集し、スタッフの追加・削除ができます。

## 作業種別

回送 / 車両納車準備 / 積載車納車 / その他事務

## データの保存先

起動時に自動で判定し、ヘッダー右上に現在のモードを表示します。

| 表示 | 状態 | データの置き場所 |
|---|---|---|
| 社内サーバーで共有中 | `server.js` または `api.php` が同じ場所にある | サーバー上の `data.json`（全員で共有） |
| 全員で共有中 | claude.ai の Artifact として公開されている | Artifact のデータベース（全員で共有） |
| この端末のみに保存 | HTMLファイルを直接開いた | そのブラウザ内（共有されません） |

社内サーバーへの設置手順は **[SETUP.md](SETUP.md)** を参照してください。

## ファイル

| ファイル | 用途 |
|---|---|
| `index.html` | アプリ本体（単一ファイル、ビルド不要） |
| `server.js` | 社内サーバー用（Node.js版・追加インストール不要） |
| `api.php` | 社内サーバー用（PHP版） |
| `start.bat` / `start.sh` | Node.js版の起動用 |
| `.htaccess` | PHP版でデータファイルを保護（Apache用） |
| `SETUP.md` | 社内サーバーへの設置手順 |

`data.json`（データ本体）と `data.bak.json`（直前の状態）はサーバー起動後に自動生成されます。
