# 車両入出庫管理ツール

自動車ディーラー向けの、**受注済み・納車前車両の所在管理**ツールです。
`index.html` をブラウザで開くだけで動作します。インストール・サーバー不要。

月100台規模の入出庫を想定しています。

## 使い方

1. `index.html` をダブルクリック（または右クリック→プログラムから開く→Chrome / Edge）
2. 「設定」タブで **拠点**・**外部業者**・**自社情報** を登録
3. 「CSV取込」タブで基幹システムから出力したCSVを読み込む
4. 「車両一覧」タブで入庫・出庫・移動を登録
5. 「帳票作成」タブで納車依頼書・車両伝票を印刷 / PDF保存

## 機能

### ダッシュボード
納車前の総台数、未入庫、納車準備完了、7日以内の納車、**納車予定日の超過**、予定日未設定の件数を一覧表示。
拠点別・ステータス別の台数と、直近30日の納車予定表も確認できます。

### CSV取込（列マッピング対応）
- 基幹システムのCSV列と、本ツールの項目を**画面上で対応づけ**できます。列名から自動で対応づけを試み、対応づけは保存されて次回以降自動復元されます。
- 文字コードは **UTF-8 / Shift_JIS を自動判別**します（Excel由来のCSVでもそのまま読めます）。
- **注文書番号をキーに突合**し、既存車両は更新、新規は追加します。同じCSVを再取込しても重複しません。
- 取込前にプレビューで「新規 / 更新 / 変更なし / 対象外」の件数と、変更されるセルを確認できます。
- 既定では、画面で更新した**拠点・ステータスをCSVで上書きしません**（オプションで変更可）。

### 車両一覧
- フリーワード検索、拠点・ステータス・納車予定日の範囲での絞り込み、各列でのソート。
- 行ごとの **入庫 / 移動 / 出庫 / 編集**。
- チェックボックスで複数選択して、**一括での拠点移動・ステータス変更・帳票作成・削除**。
- 納車予定日を過ぎた車両には「超過」バッジが付きます。
- 表示中の一覧をCSV出力できます。

### 所在管理
**拠点（保管場所）× ステータス** の2軸で管理します。

- 拠点：設定タブで自由に追加・削除（初期値：本社ヤード / 第2ヤード / 整備工場 / 外部ヤード / 陸送中）
- ステータス：受注済（未入庫）→ 入庫済 → 整備中 → 納車準備完了 → 陸送中 → 納車済

### 入出庫履歴
すべての入庫・出庫・移動・ステータス変更・CSV取込・帳票発行を、日時・変更前後・担当者つきで記録します。
種別・期間・フリーワードで絞り込み、CSV出力が可能です。

### 帳票作成
- **納車依頼書**：外部業者向け。複数台をまとめて1枚に記載。宛先業者・希望納車日・連絡事項を指定できます。
- **車両伝票**：積載用。1台1枚、A4縦1ページに収まるよう調整済み。積載・輸送記録欄と押印欄つき。

いずれもブラウザの印刷機能からA4で印刷、またはPDFとして保存できます。

> **帳票フォーマットについて**
> 現在は一般的なレイアウトによる**暫定版**です。御社指定のフォーマット（Excel / PDF）をご共有いただければ、それに合わせて作り込みます。

### バックアップ / 復元
データはこのブラウザ内（localStorage）にのみ保存されます。
PCの入れ替えや共有の際は、必ず設定タブからJSONバックアップを書き出してください。

## 注意事項

- データはブラウザごと・PCごとに保存されます。**複数人での同時共有はできません**。共有が必要になった場合はサーバー構成への移行が必要です。
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと、保存データも消えます。**定期的なバックアップを推奨**します。
- 動作確認済みブラウザ：Google Chrome / Microsoft Edge
